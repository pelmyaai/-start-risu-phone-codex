RisuAI 폰용 ChatGPT/Codex 연결 가이드

노트북에서 ChatGPT/Codex 연결 서버를 켜두고, iPhone이나 Galaxy의 RisuAI가 HTTPS 주소로 접속하게 만드는 가이드입니다. 공유할 때도 한 사람 계정을 같이 쓰는 방식이 아니라, 각자 자기 노트북에서 자기 ChatGPT/Codex 계정으로 로그인하는 흐름을 기준으로 합니다.

Windows iPhone / Galaxy RisuAI clawgate Cloudflare Quick Tunnel

먼저 읽기

Cloudflare 주소를 다른 사람에게 주면, 그 사람의 요청이 내 ChatGPT/Codex 계정으로 나갑니다. 공개 채팅방이나 커뮤니티에 주소를 올리지 마세요. 공유용으로 설명할 때는 반드시 각자 자기 노트북에서 자기 계정으로 로그인하게 안내하세요.
  • 이 방식은 노트북을 켜두는 동안만 작동합니다.
  • 노트북이 꺼지거나 절전 모드로 들어가면 연결이 끊깁니다.
  • Cloudflare Quick Tunnel 주소는 임시 주소라서 다시 실행할 때 바뀔 수 있습니다.
  • iPhone과 Galaxy 모두 가능합니다. 핵심은 폰 RisuAI가 HTTPS 주소에 접속하는 것입니다.

전체 구조

폰이 노트북으로 직접 붙지 않고, Cloudflare 임시 HTTPS 주소를 한 번 거쳐서 노트북의 clawgate에 연결됩니다.

1. iPhone / Galaxy RisuAI
2. https://...trycloudflare.com
3. 내 노트북의 clawgate
4. 내 ChatGPT/Codex 계정

1. 처음 한 번만: 필요한 프로그램 확인

처음 쓰는 사람은 이 단계를 먼저 합니다. 이미 clawgate status가 로그인 상태이고 cloudflared --version이 정상으로 뜨면 바로 2번으로 넘어가도 됩니다.

먼저 Windows에서 PowerShell 창을 엽니다. 시작 버튼을 누르고 PowerShell을 검색한 뒤 Windows PowerShell을 실행하세요. 아래 명령어들은 모두 그 PowerShell 창에 한 줄씩 입력하고 Enter를 누르면 됩니다.

clawgate status
cloudflared --version

clawgate가 로그인되어 있지 않으면 아래 명령어를 실행하고, 뜨는 주소로 들어가 ChatGPT/Codex 계정으로 로그인합니다.

clawgate login

cloudflared가 없다면 아래 명령어로 설치합니다.

winget install -e --id Cloudflare.cloudflared

2. 매번 사용할 때: 더블클릭으로 켜기

1번 준비가 끝난 뒤부터는 노트북을 껐다 켜도 아래 파일만 더블클릭하면 됩니다. 새 터널 주소가 클립보드에 복사되고, 같은 주소가 txt 파일에도 저장됩니다.

RisuAI-Phone-Codex.cmd

바탕화면 바로가기를 만들고 싶으면 create-desktop-shortcut.ps1을 실행하면 됩니다.

3. 실행되면 확인할 창

RisuAI-Phone-Codex.cmd를 더블클릭하면 두 개의 PowerShell 창이 열립니다.

  • 첫 번째 창: clawgate --host=0.0.0.0 --port=8082
  • 두 번째 창: cloudflared tunnel --url http://localhost:8082 --protocol http2

실행기가 새 Cloudflare 주소를 찾으면 자동으로 클립보드에 복사합니다.

주소는 latest-risu-phone-url.txt에도 저장됩니다. 클립보드 복사가 실패하면 이 파일을 열어서 복사하세요.

4. 폰 브라우저에서 먼저 확인

폰 RisuAI에 넣기 전에 iPhone Safari나 Galaxy Chrome에서 복사된 주소를 먼저 열어봅니다.

https://새주소.trycloudflare.com

정상이면 아래처럼 보입니다.

{"message":"clawgate ...","status":"ok"}
브라우저에서 먼저 열리는지 확인하면 Risu 설정 문제와 터널 문제를 쉽게 구분할 수 있습니다.

5. RisuAI 설정

폰 RisuAI에서 Custom API를 선택하고 아래처럼 넣습니다. URL만 실행기가 복사해준 주소로 바꿉니다.

먼저 안녕처럼 짧은 메시지로 테스트하세요. 성공하면 필요에 따라 Response streaming을 켜서 다시 시험해볼 수 있습니다.

6. 자주 나는 오류

1003 오류

Risu 설정이 맞지 않거나 앱이 주소에 제대로 요청하지 못하는 경우가 많습니다. URL이 https://로 시작하는지, Autofill Request URL이 꺼져 있는지 확인하세요.

1016 또는 DNS 오류

Cloudflare 임시 주소가 죽었거나 잘못 복사된 상태입니다. 실행기를 다시 더블클릭해서 새 주소를 받으세요.

폰 브라우저에서도 안 열림

터널이 아직 준비되지 않았거나 cloudflared가 꺼진 상태입니다. 20초 정도 기다린 뒤 다시 열어보고, 계속 안 되면 실행기를 다시 켭니다.

노트북을 닫으면 끊김

정상입니다. 이 방식은 노트북이 서버 역할을 하므로 절전 모드를 끄고 충전기를 연결해두는 것이 좋습니다.

나중에 할 수 있는 고급 방식

주소를 매번 바꾸기 싫다면 Cloudflare 고정 터널을 만들 수 있습니다. 노트북을 아예 안 켜고 싶다면 VPS나 Oracle Cloud Always Free 같은 가상 서버에 clawgate를 올리는 방법이 있습니다.

고급 방식은 ChatGPT/Codex 로그인 토큰이 서버에 저장되므로 보안 설정을 더 신중하게 해야 합니다. 이 문서의 v1 기본 방식은 노트북에서 직접 켜는 Quick Tunnel입니다.
이 문서는 개인 테스트용 가이드입니다. 계정 공유, 재판매, 공개 프록시 운영 용도로 사용하지 마세요.
