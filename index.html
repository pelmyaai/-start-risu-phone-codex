GCP 가상컴으로 RisuAI 폰 Codex 연결하기

노트북을 켜두지 않고도 iPhone이나 Galaxy의 RisuAI에서 자기 ChatGPT/Codex 계정을 쓰기 위한 가이드입니다. Google Cloud VM에 작은 서버를 켜고, 폰 RisuAI는 그 서버 주소로 접속합니다.

GCP VM Ubuntu iPhone / Galaxy RisuAI ChatGPT/Codex

먼저 읽기

이 방식은 각자 자기 Google Cloud VM과 자기 ChatGPT/Codex 계정을 쓰는 방식입니다. 다른 사람에게 내 서버 주소와 비밀번호를 주면 그 사람이 내 ChatGPT/Codex 계정을 쓰게 됩니다.
  • 노트북을 꺼도 됩니다. 대신 GCP VM은 켜져 있어야 합니다.
  • GCP는 무료 크레딧이나 무료 티어를 쓸 수 있지만, 설정에 따라 과금될 수 있습니다.
  • 처음에는 Response streaming을 끄고 테스트하는 것을 추천합니다.
  • iPhone과 Galaxy 모두 같은 방식으로 쓸 수 있습니다.

전체 구조

폰 RisuAI가 GCP VM에 열린 HTTPS 주소로 접속하고, VM 안의 clawgate가 ChatGPT/Codex 계정으로 요청을 넘깁니다.

필요한 파일

GCP VM에 업로드할 파일은 이것 하나입니다. GitHub에서 이 파일을 내려받아 VM의 SSH 창에 업로드하세요.

for_linux_codex.zip

1. GCP VM 만들기

Google Cloud Console에서 Compute Engine VM 인스턴스를 만듭니다. 처음이면 아래 순서대로 누르면 됩니다.

1-1. Compute Engine으로 이동

  • Google Cloud Console을 엽니다.
  • 왼쪽 메뉴에서 Compute Engine을 찾습니다.
  • VM 인스턴스로 들어갑니다.
  • 인스턴스 만들기 또는 Create instance 버튼을 누릅니다.

1-2. 기본 정보 설정

  • 이름은 아무거나 정해도 됩니다. 예: risu-codex-phone
  • 리전은 무료 티어를 노리면 us-central1 같은 무료 티어 대상 리전을 고릅니다.
  • 머신 유형 또는 머신 타입에서 e2-micro를 고릅니다.

1-3. OS와 디스크 설정

  • OS 및 스토리지 또는 Boot disk에서 변경을 누릅니다.
  • 운영체제는 Ubuntu를 고릅니다.
  • 버전은 Ubuntu LTS를 고릅니다. Minimal 버전이 따로 보이면 일반 LTS 쪽을 고르는 것을 추천합니다.
  • 부팅 디스크 유형은 표준 영구 디스크를 권장합니다.
  • 디스크 크기는 큰 용량이 필요 없습니다. 무료 티어를 노리면 30GB 이하를 권장합니다.

1-4. 네트워크와 생성

  • 이 패키지는 Cloudflare 터널을 쓰므로, 보통 HTTP/HTTPS 방화벽 체크를 따로 켤 필요는 없습니다.
  • 설정이 끝나면 만들기 또는 Create를 누릅니다.
  • 잠시 기다리면 VM 인스턴스 목록에 새 서버가 생깁니다.
  • 서버가 만들어지면 같은 줄의 SSH 버튼을 눌러 접속합니다.
예상 과금액이 보일 수 있습니다. 무료 크레딧/무료 티어 적용 여부는 계정 상태와 설정에 따라 다르니 GCP 예산 알림을 켜두세요.
사진을 넣는다면 이 섹션에 4장이 있으면 충분합니다: VM 인스턴스 만들기 버튼, e2-micro 선택, Ubuntu 부팅 디스크 선택, SSH 버튼 위치.

2. SSH 열고 zip 업로드

VM이 만들어지면 GCP 화면에서 SSH 버튼을 누릅니다. SSH 창이 열리면 오른쪽 위의 파일 업로드로 for_linux_codex.zip을 올립니다.

3. 압축 풀기

SSH 창에 아래 명령어를 통째로 복사해서 붙여넣고 Enter를 누르세요.

sudo apt update
sudo apt install -y unzip
unzip for_linux_codex.zip
cd for_linux_codex

4. 설치하기

아래 명령어를 SSH 창에 붙여넣고 Enter를 누르세요.

bash setup_user.sh
source ./env.sh
설치 중 시간이 조금 걸릴 수 있습니다. 완료되면 다음 단계로 갑니다.

5. ChatGPT/Codex 로그인

아래 명령어를 실행합니다.

bash login.sh

SSH 창에 긴 주소가 뜨면 그 주소를 브라우저로 열고, 자기 ChatGPT/Codex 계정으로 로그인하세요. 끝나면 다시 SSH 창으로 돌아옵니다.

6. 서버 켜기

아래 명령어를 실행합니다.

bash start_detached.sh

Risu API password:가 나오면 RisuAI에 넣을 비밀번호를 직접 정해서 입력하세요.

비밀번호를 입력할 때 화면에 글자가 안 보이는 것은 정상입니다. 입력하고 Enter를 누르면 됩니다.

7. 나온 주소 복사

성공하면 이런 정보가 나옵니다.

base_url=https://어쩌구.trycloudflare.com
api_password=내가_방금_만든_비밀번호
format=Anthropic Claude
model=claude-3-opus

폰 RisuAI에 넣을 것은 base_url과 api_password입니다.

다시 켤 때

서버 주소가 죽었거나 VM을 다시 켰다면 SSH에서 아래만 다시 실행합니다.

cd for_linux_codex
source ./env.sh
bash start_detached.sh

서버 끄기

cd for_linux_codex
bash stop.sh

자주 나는 문제

폰에서 401 오류

RisuAI의 API password가 틀렸을 가능성이 큽니다. connection-info.txt 또는 실행 결과에 나온 비밀번호를 다시 확인하세요.

1016 또는 DNS 오류

Cloudflare 임시 주소가 죽은 상태입니다. SSH에서 bash start_detached.sh를 다시 실행해서 새 주소를 받으세요.

로그인이 풀림

bash login.sh를 다시 실행해서 ChatGPT/Codex 계정으로 다시 로그인합니다.
